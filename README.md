# DARTS ATS

Внутренний кабинет агентства DARTS: база кандидатов, заказчики, вакансии и воронка. Данные живут в браузере (`localStorage`), демо подставляется при первом запуске.

## Запуск

```bash
cd ~/ats-darts
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## С чего начать

1. **Обзор** — цифры и открытые вакансии.
2. **Поиск** — запрос + город + навык по внутренней базе.
3. **Вакансия** — канбан этапов, «взять на вакансию».
4. **Кандидат** — резюме, заметки, привязка к проектам.

Кнопка «Сбросить демо-данные» в сайдбаре возвращает стартовый набор.
